Entry for the [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) bounty on make.fun.

`main.py` writes a two-line explanation of an everyday thing to `/output/entry.txt`: line 1 explains it to a 10-year-old in one vivid sentence built on an analogy; line 2 says what the analogy maps and what it leaves out.

Run it with:

```sh
python3 main.py
```
